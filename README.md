# LEGAL MIND — interactive hero concept

This repository contains an initial Hebrew RTL hero prototype built for design exploration, not a functioning AI service.

Run with `npm install`, then `npm run dev`.

Visual direction: warm off-white, deep teal #014345, turquoise #36A8B3, a fine circuit-board-inspired background, a professional question/answer interaction, and two minimal business routes.

IMPORTANT: Add approved Logo.svg and licensed Polin font files locally. Do not commit commercial font files to a public repo. The graphic circuitry is proposed art, not the approved dots.svg brand asset. Review all copy and routes before client delivery.
